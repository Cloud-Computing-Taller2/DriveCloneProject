# Demo: NMAP + Cloudflare Tunnel

## NMAP

Scan only hosts you own. Never scan Cloudflare edge IPs.

```bash
nmap -sS -sV -p 80,443,4566,5432 <demo-host>
```

Expected on the demo host: 80 (NGINX), 5432 (PostgreSQL), 4566 (LocalStack).
If the stack runs behind the tunnel only, 80 may not be exposed; scan the origin host instead.

## Cloudflare Tunnel (named tunnel)

1. Create the tunnel and DNS record in Cloudflare, then put the token in `.env` as `TUNNEL_TOKEN`.
2. Start the connector attached to the Compose network:

```bash
./scripts/tunnel.sh
```

The script runs `cloudflare/cloudflared` with `tunnel run --token`, so no config file with secrets is committed. Add the public hostname to `public_app_origin` and re-apply Terraform so S3 CORS accepts browser requests from it:

```bash
cd infra && terraform apply -var="public_app_origin=https://driveclone.example.com" -auto-approve
```

Presigned URLs generated by the API must use `S3_PUBLIC_ENDPOINT` reachable from the browser (for the demo, the LocalStack host or a public tunnel to port 4566). Internal API/worker calls keep `AWS_ENDPOINT_URL=http://localstack:4566`.

## Contingency: quick tunnel

No token or DNS needed, but the URL is ephemeral:

```bash
docker run --rm --network driveclone_default cloudflare/cloudflared:latest tunnel --no-autoupdate --url http://nginx:80
```

Copy the printed `*.trycloudflare.com` hostname into `public_app_origin` before the demo.
